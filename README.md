# UltratechApp

Aplicación ecommerce desarrollada en Android Studio usando Java.

## Características
- Inicio de sesión
- Perfil de usuario
- Búsqueda de productos
- Productos guardados
- Vista detalle de productos

## Estructura del proyecto

### Activities
- LoginActivity
- HomeActivity
- ProfileActivity
- SearchActivity
- SavedActivity

### Packages
- adapters
- models
- repositories
- services
- utils

## Tecnologías
- Java
- Android Studio
- RecyclerView
- Gradle
